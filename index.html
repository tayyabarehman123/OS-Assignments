🖥️ Linux

    Linux is an open-source operating system just like Windows or macOS but it's free and customizable.
    It acts as a bridge between your computer's hardware (like CPU, RAM, hard drive) and the software (like applications and programs).
    When you turn on a Linux machine:
    Linux controls hardware
    Linux manages files and processes
    Linux provides a platform to run programs

🌐 Kernal

    The kernel is the core part of an operating system that manages communication between hardware and software.
    It controls processes, memory, devices, and file systems to keep everything running smoothly.

  • echo "Hello World" — Print text to screen.

🖥️ Navigating Directories

  • cd — Move to the home directory from the current directory.
  • cd / — Move to the root directory (frpm top level directory) .
  • cd .. — Move one step(one directory) backward.
  • cd dir-name — Move to a specific directory named in the command.
  • ls — Show all files and folders in the current directory.
  • ls -l — Show detailed information (permissions, size, date) about files and folders.
  • ls -r — List files and folders in the reverse order.
  • ls -a — Show all hidden and unhidden files.
  • pwd — Print the full path of your current working directory.

🔗 Stream, Redirection & Pipes

Streams:
In computers, a stream is just the flow of data. When data comes into the computer (input), or goes out from it (output), it's called a stream.

Linux Commands use three types of streams:

Standard Input (stdin): Input, usually from keyboard.
Standard Output (stdout): Output to screen (results).
Standard Error (stderr): Error messages sgow on screen.

I/O Redirection:
Redirection means changing where input comes from or where output goes. Normally, input comes from keyboard and output goes to
the screen, but with redirection, we can change this.

Redirection Operators:

  • > — Send output to a file (overwrite it if exists).
  • >> — Send output to the end of a file (append) .
  • < — Take input from a file instead of keyboard.
  • << — Used mostly in shell scripting for input.
  • | — Send output of one command as input to another command.

    • Pipes:
    Send output of one command into another command.

    Format:CommandA | CommandB

    cat file.txt | sort

    This sorts the contents of file.txt.

    • ps — Show currently running processes.
    • bg — Resumes a suspended job in the background.
    • fg — Brings a background job to the foreground.
    • kill PID — Terminate a process using it;s Process ID.

    🛠️ Permissions

    • chmod — Change permissions (read, write, execute) of a file.
    • Read (r) — This permission in a directory means you can use the ls command to the filenames.
    • Write (w) — This permission in a directory means you can add files from the directory.
    • Execute (x) — This permission in a directory means you can use the cd command to change the directory.

    🖊️ uname

      Displays a system information like OS name and Kernal version.

    • -n — Print the network node hostname.
    • -r — Print the Kernal release.
    • -v — Print the Kernal version.
    • -m — Print the machine hardware name.

    • -o — Print the operating system.
    • -a — Print all available system.

    🔀 sort

      Sort lines in a file alphabetically. Output shows on terminal by default but can be redirected to a file.

    • -b — Ignore leading blanks.
    • -r — Sort in reverse order.
    • -f — Ignore case difference (A=a).
    • -k — Sort based on a specific column.
    • -n — Sort numbers by their arithmetic values.

    ⚙️ System Programming (C Language)

    🔹 system() Function

    Runs a shell command inside a C program.

    #include <stdlib.h>
int main() {
    system("ls -l");
    return 0;
}

    🔹 fork() - Create a New Process

    Creates a child process.

    #include <unistd.h>
#include <stdio.h>
int main() {
    fork();
    printf("Hello Process\n");
    return 0;
}

    🔹 exec() - Replace Current Process

    Runs a different program inside current process.

    #include <unistd.h>
int main() {
    execl("/bin/ls", "ls", "-l", NULL);
    return 0;
}

    🔹 wait() - Wait for Child

    Parent waits for child process to finish.

    #include <sys/wait.h>
#include <unistd.h>
int main() {
    fork();
    wait(NULL);
    return 0;
}

    🔹 exit() - End a Program

    #include <stdlib.h>
int main() {
    exit(0);
}

    🔹 getpid() and getppid()

    getpid() — Get current process ID, getppid() — Get parent process ID.

    #include <unistd.h>
#include <stdio.h>
int main() {
    printf("My PID: %d\n", getpid());
    printf("My Parent PID: %d\n", getppid());
    return 0;
}
